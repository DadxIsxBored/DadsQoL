# DadsQoL

One configurable plugin for Valheim 1.0.12:

- Base carry weight: `5000` by default.
- Automatic pickup radius: `6` meters by default.
- Hand equipment remains usable while swimming.

Each feature and the complete plugin can be switched on or off in `BepInEx/config/com.dadisbored.dadsqol.cfg`.

Requires BepInEx only. This is a client-side plugin.
